# GitHub Copilot Instructions

You are helping refactor a legacy Flask Sudoku application built with Flask, HTML, CSS, and JavaScript.

Follow these requirements when generating code:

- Preserve all existing functionality unless explicitly instructed otherwise.
- Keep the application modular and easy to maintain.
- Use meaningful function and variable names.
- Avoid duplicate code whenever possible.
- Keep HTML, CSS and JavaScript separated.
- Follow Python and JavaScript best practices.
- Add concise comments only where they improve readability.
- Add basic error handling for invalid inputs and failed requests.
- Ensure every generated Sudoku puzzle has exactly one unique solution.
- Keep all existing API endpoints working.
- Maintain compatibility with the current project structure.
- Make the interface responsive for desktop and mobile devices.
- Ensure buttons and text remain readable in both Light Mode and Dark Mode.
- Keep the Sudoku board centered and maintain alternating 3×3 block colors.
- Implement reusable helper functions whenever possible.
- Preserve accessibility by using readable font sizes and sufficient color contrast.
- Do not introduce unnecessary external libraries.
